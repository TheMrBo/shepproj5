# Delicious — recipe front page

A responsive, buildless HTML/CSS/JavaScript recreation inspired by the supplied cooking-app video. An integrated app layout uses a sidebar on desktop and bottom navigation on mobile. Recipe cards open an accessible detail dialog with keyboard dismissal and focus restoration.

Run `python -m http.server 5173` (or `npm run dev`) and visit http://localhost:5173.

Includes Discover and Saved screens, recipe search, category filters, saved recipes stored in this browser, recipe selection, and detail/recipe tabs. Recipe content and ratings are illustrative demo data. Artwork in `assets/` was extracted from the user-provided video. Fonts load from Google Fonts with local sans-serif fallbacks. No backend or dependencies are required.
